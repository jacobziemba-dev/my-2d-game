# my-2d-game

Small 2D top-down game built with Vite.

Getting started

- Install dependencies:

```powershell
npm install
```

- Run development server:

```powershell
npm run dev
```

Open http://localhost:5173 in your browser (Vite default).

Build

```powershell
npm run build
```

Preview the production build:

```powershell
npm run preview
```

Testing

This project uses Vitest for tests. To run tests:

```powershell
npm test
```

Linting & formatting

- Lint: `npm run lint`
- Fix lint issues: `npm run lint:fix`
- Format: `npm run format`
- Check format: `npm run format:check`

Notes

- Project is an ES module project (`type: module` in `package.json`).
- If you add new editor integrations, see `.vscode/extensions.json` for recommended extensions.
